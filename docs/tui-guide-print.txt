
🚀 Purple Code TUI 사용 가이드
========================


이 문서는 **Purple Code**의 TUI를 처음 설치하고, 홈 화면과 `Ctrl+P` 커맨드 팔레트, 세션 화면까지 익힐 수 있게 정리한 가이드입니다.


────────────────────────────────────────



1. Purple Code 릴리즈 버전 설치하기
--------------------------



■ 터미널에서 설치



[code: bash]
  curl -fsSL https://github.com/JeongEEE/opencode/releases/latest/download/install | bash
[end code]


다른 패키지 매니저 설치는 지원하지 않고, 위 **Purple Code 릴리즈 설치 스크립트만 사용**하면 됩니다.

설치가 끝났다면 새 터미널을 열거나 셸을 다시 불러옵니다.


[code: bash]
  source ~/.zshrc   # zsh 사용 시
  source ~/.bashrc  # bash 사용 시
[end code]



■ 설치 확인



[code: bash]
  pcode --version
[end code]



■ 실행


설치 후에는 프로젝트 디렉터리에서 `pcode` 명령으로 실행하면 됩니다.


[code: bash]
  cd <프로젝트 경로>
  pcode
[end code]



[code: bash]
  pcode /path/to/project
[end code]



────────────────────────────────────────



2. 🏠 Purple Code TUI 홈 화면 이해하기
------------------------------


Purple Code를 실행하면 먼저 **홈 화면**이 열립니다. 여기서는 바로 프롬프트를 입력해 새 작업을 시작할 수 있습니다.


■ 홈 화면 구성


• 상단에는 Purple Code 로고가 표시됩니다.
• 가운데에는 프롬프트 입력창이 있습니다.
• 입력창에는 예시 문구가 돌아가며 표시됩니다.
  - `코드베이스에서 TODO 수정하기`
  - `이 프로젝트의 기술 스택은 무엇인가요?`
  - `실패한 테스트 수정하기`
• 셸 모드 예시로는 `ls -la`, `git status`, `pwd` 같은 명령도 보입니다.
• 하단 푸터에는 현재 디렉터리, Git 브랜치, MCP 연결 상태, 버전 정보가 표시됩니다.


■ 홈 화면에서 바로 할 수 있는 것


• 자연어로 요청 입력 후 `Enter`로 바로 시작
• `@파일명` 으로 파일 첨부
• `!명령어` 로 셸 명령 실행
• `Tab` 으로 `Build` 와 `Plan` 에이전트 전환


■ 처음 실행했을 때


처음 실행했는데 아직 모델 공급자가 연결되어 있지 않다면, 먼저 `/connect` 로 공급자를 연결하는 흐름부터 진행하면 됩니다. 이후에 프롬프트를 보내면 세션 화면으로 넘어갑니다.


■ 팁 영역


홈 화면 아래쪽에는 팁 영역이 나타날 수 있습니다. 이 영역은 커맨드로 켜고 끌 수 있고, 표시 상태는 저장됩니다.

• `Ctrl+P` 를 눌러 커맨드 팔레트를 연 뒤
• `팁 표시` 또는 `팁 숨기기` 를 실행하면 됩니다.


────────────────────────────────────────



3. ⌨️ 가장 먼저 익히면 좋은 기본 입력법
-------------------------


TUI는 단순 채팅창이 아니라, 프롬프트 안에서 여러 기능을 같이 쓰는 방식입니다.


■ 파일 첨부


메시지에서 `@` 뒤에 파일명을 입력하면 현재 작업 디렉터리 기준으로 **퍼지 검색**이 열리고, 선택한 파일이 컨텍스트에 첨부됩니다.



■ 셸 명령 실행


메시지를 `!` 로 시작하면 셸 명령을 바로 실행할 수 있습니다.


[code: bash]
  !git status
[end code]


실행 결과는 대화에 도구 결과로 붙습니다.


■ 이미지 / PDF 추가


• 이미지나 PDF를 터미널에 드래그 앤 드롭
• 또는 `Ctrl+V` 로 클립보드 이미지 붙여넣기


■ 여러 줄 입력


• `Shift+Enter` 또는 `Ctrl+J` : 줄바꿈 추가
• `Ctrl+C` : 입력 중인 프롬프트 지우기
• `Escape` : 응답 생성 중 중단


────────────────────────────────────────



4. 🔎 `Ctrl+P` 커맨드 팔레트 사용법
-------------------------


`Ctrl+P` 는 Purple Code TUI에서 가장 중요한 단축키 중 하나입니다. 현재 화면에서 사용할 수 있는 **작업과 커맨드**를 검색해서 실행할 수 있습니다.


■ 열기


• `Ctrl+P` : 커맨드 팔레트 열기

팔레트가 열리면 키워드를 입력해서 명령을 필터링할 수 있습니다.


■ 카테고리


커맨드 팔레트는 현재 컨텍스트에 따라 다음 카테고리로 명령을 보여줍니다.

• `추천`
• `세션`
• `에이전트`
• `공급자`
• `시스템`


■ 자주 쓰는 명령


#### 세션 관련

• `새 세션` - `Ctrl+X N`, `/new`
• `세션 목록` - `Ctrl+X L`, `/sessions`
• `세션 압축` - `Ctrl+X C`, `/compact`
• `이전 메시지 취소` - `Ctrl+X U`, `/undo`
• `다시 실행` - `Ctrl+X R`, `/redo`
• `메시지로 이동` - `Ctrl+X G`, `/timeline`
• `세션 대화록 내보내기` - `Ctrl+X X`, `/export`
• `세션 공유` - `/share`
• `세션 공유 해제` - `/unshare`
• `세션 이름 변경` - `/rename`

#### 에이전트 / 모델 관련

• `모델 전환` - `Ctrl+X M`, `/models`
• `에이전트 전환` - `Tab`
• `에이전트 선택` - `Ctrl+X A`, `/agents`
• `변형 순환` - `Ctrl+T`
• `MCPs 전환` - `/mcps`

#### 시스템 관련

• `상태 보기` - `Ctrl+X S`, `/status`
• `테마 전환` - `Ctrl+X T`, `/themes`
• `언어 변경` - 커맨드 팔레트에서 `언어 변경` 선택 후 `English` 또는 `한국어` 선택
• `도움말` - `/help`
• `문서 열기` - `Open docs`
• `앱 종료` - `/exit`, `/quit`, `/q`
• `터미널 일시 중단` - `Ctrl+Z`

#### 프롬프트 관련

• `외부 에디터 열기` - `Ctrl+X E`, `/editor`
• `스킬 목록` - `/skills`


■ 기억하면 좋은 점


• `Ctrl+X` 는 기본 **리더 키**입니다.
• 예를 들어 `Ctrl+X N` 은 `Ctrl+X` 를 누른 뒤 `N` 을 누르는 방식입니다.
• 홈 화면과 세션 화면에 따라 보이는 명령이 조금 달라질 수 있습니다.
• 일부 커맨드는 기본 단축키 없이 **커맨드 팔레트나 슬래시 커맨드 중심**으로 제공됩니다.
• `언어 변경`, `바텀바 표시`, `바텀바 숨기기` 같은 항목은 `Ctrl+P`에서 검색해서 쓰는 게 가장 빠릅니다.


────────────────────────────────────────



5. 💬 세션 화면 사용법
--------------


프롬프트를 한 번 보내면 홈 화면에서 **세션 화면**으로 이동합니다. 여기서 실제 대화, 파일 작업, 툴 실행 결과, 되돌리기 같은 기능을 모두 사용합니다.


■ 세션 화면 구성


• 중앙: 대화 메시지 타임라인
• 하단: 프롬프트 입력창
• 우측 사이드바: 세션 정보, 컨텍스트, MCP/토큰 관련 정보
• 바텀바: 세션 제목, 현재 디렉터리, 브랜치, 사용량 정보

사이드바는 넓은 터미널에서 자동으로 보일 수 있고, 바텀바는 표시/숨김이 가능합니다.


■ 자주 쓰는 세션 기능


#### 메시지 이동

• `PageUp` / `PageDown` : 대화 내역 페이지 이동
• `Ctrl+G` 또는 `Home` : 첫 메시지로 이동
• `Ctrl+Alt+G` 또는 `End` : 마지막 메시지로 이동
• `Ctrl+X G` 또는 `/timeline` : 특정 메시지로 점프

#### 보기 설정

• `Ctrl+X B` : 사이드바 표시 / 숨기기
• `바텀바 표시` / `바텀바 숨기기` : 커맨드 팔레트에서 전환
• `Ctrl+X H` : 코드 블록 가시성 전환
• `타임스탬프 표시` / `타임스탬프 숨기기` : 커맨드 팔레트 또는 `/timestamps`
• `생각 표시` / `생각 숨기기` : `/thinking`
• `도구 세부 정보 표시` / `도구 세부 정보 숨기기` : 커맨드 팔레트에서 전환


■ 언어 변경


Purple Code TUI는 커맨드 팔레트에서 언어를 바꿀 수 있습니다.

1. `Ctrl+P` 를 눌러 커맨드 팔레트를 엽니다.
2. `언어 변경` 을 검색해 선택합니다.
3. `English` 또는 `한국어` 중 원하는 언어를 고릅니다.

언어를 바꾸면 커맨드 이름과 일부 UI 텍스트도 함께 바뀝니다.


■ 바텀바 표시 / 숨기기


세션 화면 아래쪽의 바텀바에는 **세션 제목, 현재 디렉터리, Git 브랜치, 사용량 정보**가 표시됩니다.

필요 없으면 `Ctrl+P` 에서 `바텀바 숨기기` 를 실행하고, 다시 보고 싶으면 `바텀바 표시` 를 실행하면 됩니다. 바텀바가 숨겨진 상태에서는 하단 입력 영역 쪽에서 사용량 정보가 더 직접 보일 수 있습니다.

#### 대화 관리

• `Ctrl+X U` 또는 `/undo` : 마지막 사용자 메시지와 파일 변경 되돌리기
• `Ctrl+X R` 또는 `/redo` : 방금 취소한 변경 복원
• `Ctrl+X Y` : 마지막 어시스턴트 메시지 복사
• `Ctrl+X X` 또는 `/export` : 세션을 Markdown으로 저장
• `/copy` : 세션 대화록 전체를 클립보드에 복사
• `/fork` : 특정 메시지 지점에서 새 세션 분기

#### 공유

• `/share` : 현재 세션 공개 링크 생성 또는 기존 링크 복사
• `/unshare` : 공개 링크 해제


■ 세션 화면에서 보이는 상태들


• 응답 생성 중에는 진행 상태가 표시됩니다.
• 중단된 응답은 `interrupted` 상태로 보일 수 있습니다.
• 아직 처리 대기 중인 응답은 `QUEUED` 로 표시될 수 있습니다.
• 권한이 필요한 작업은 허용/거부 프롬프트가 별도로 뜹니다.


■ 권한 요청은 어떻게 보나?


Purple Code가 파일 편집, 셸 실행, 외부 경로 접근 같은 작업을 하려면 세션 중간에 **권한 승인 화면**이 뜰 수 있습니다. 이때는 보통 다음 중 하나를 선택하면 됩니다.

• 한 번만 허용
• 항상 허용
• 거부

즉, 세션 화면은 단순히 답변만 보는 화면이 아니라, **실행과 승인까지 함께 관리하는 작업 공간**이라고 보면 됩니다.


────────────────────────────────────────



6. 🧭 서브에이전트 세션 보기
-----------------


일부 작업에서는 하위 세션이 생길 수 있습니다. 이 경우 서브에이전트 전용 푸터가 나타나고, 부모 세션과 자식 세션 사이를 이동할 수 있습니다.

• `Up` : 상위 세션으로 이동
• `Right` : 다음 하위 세션
• `Left` : 이전 하위 세션
• `Ctrl+X Down` : 첫 하위 세션으로 이동

서브에이전트 화면 아래쪽에는 `Parent`, `Prev`, `Next` 같은 힌트도 함께 표시됩니다.


────────────────────────────────────────



7. 💡 Purple Code를 처음 쓸 때 추천 흐름
------------------------------


처음에는 아래 순서로 써보면 익숙해지기 쉽습니다.

1. `pcode` 로 프로젝트에서 실행
2. 홈 화면에서 간단한 질문 입력
3. 필요하면 `@파일명` 으로 파일 첨부
4. 더 많은 기능이 필요하면 `Ctrl+P` 열기
5. 처음 실행이라면 필요에 따라 `/connect` 로 공급자 연결하기
6. `Ctrl+P` 에서 `언어 변경` 과 `바텀바 숨기기` / `바텀바 표시`도 한 번 써보기
7. 세션 화면에서 `Ctrl+X G`, `Ctrl+X X`, `Ctrl+X Y` 정도부터 익히기
8. 변경을 되돌려야 하면 `/undo`, 다시 살리려면 `/redo`

예를 들면 아래처럼 시작하면 무난합니다.


[code: text]
  이 프로젝트 구조를 빠르게 요약해줘
[end code]


또는


[code: text]
  @package.json 이 프로젝트 실행 방법을 설명해줘
[end code]

8. ✨ 자주 쓰는 팁 모음
---------------


• `Ctrl+P` 로 현재 화면에서 가능한 모든 작업을 확인할 수 있습니다.
• `Tab` 으로 `Build` 와 `Plan` 에이전트를 전환할 수 있습니다.
• `Plan` 에이전트는 실제 변경 없이 제안 위주로 볼 때 유용합니다.
• `Ctrl+V` 로 이미지를 프롬프트에 붙여넣을 수 있습니다.
• `Ctrl+X E` 또는 `/editor` 로 외부 에디터에서 긴 프롬프트를 작성할 수 있습니다.
• `Ctrl+X L` 또는 `/sessions` 로 이전 세션을 다시 열 수 있습니다.
• `Ctrl+X M` 또는 `/models` 로 모델을 바꿀 수 있습니다.
• `Ctrl+P` 에서 `언어 변경` 을 검색하면 한국어 / English 전환이 가능합니다.
• `Ctrl+P` 에서 `바텀바 숨기기` 또는 `바텀바 표시` 를 실행해 화면 밀도를 조절할 수 있습니다.
• `pcode upgrade` 로 최신 버전으로 업데이트할 수 있습니다.
